# Research Reading Workspace

这个仓库用于论文精读、研究关系整理和阶段性综合。

## 目录职责

- `inbox/`：尚未整理的论文、链接和临时材料
- `papers/`：按论文保存独立的精读记录
- `questions/`：按研究问题组织论文脉络
- `concepts/`：跨论文复用的概念卡片
- `claims/`：可验证的研究结论及其证据
- `maps/`：领域地图、方法谱系和时间线
- `syntheses/`：阶段性综述、比较和个人判断
- `experiments/`：复现实验和独立验证
- `outputs/`：报告、分享材料和最终产出
- `templates/`：新建笔记时使用的模板
- `archive/`：暂时不维护的内容

## 推荐流程

1. 将新材料放入 `inbox/`。
2. 为论文在 `papers/` 建立独立目录。
3. 将论文关联到 `questions/`、`concepts/` 和 `claims/`。
4. 在论文笔记中补充继承、改进、对立和依赖关系。
5. 定期把多个论文的关系整理到 `maps/` 和 `syntheses/`。
